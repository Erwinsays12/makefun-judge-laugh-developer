# Developer Excuse That Breaks the Judge

Entry for [Make the AI Judge Laugh: Developer Excuses](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-developer-49386be3) on make.fun.

The program writes one funny single-line excuse a developer gives when code
breaks in production to `/output/entry.txt`:

> The tests passed. All four of them. In the branch I never pushed.

The joke is a confession disguised as a defence: the tests really did pass —
they just never ran anywhere that mattered, because the branch holding them
was never pushed.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. Deterministic: it always writes the same line.
